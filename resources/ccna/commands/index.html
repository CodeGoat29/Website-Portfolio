ip arp inspection validate src-mac ip arp inspection validate dst-mac ip arp inspection validate ip ip arp inspection validate src-mac dst-mac ip

Example:SW1(config)# ip arp inspection validate src-mac dst-mac ip —Enables additional ARP validation. src-mac checks the Ethernet source MAC against the ARP sender MAC, dst- mac checks the Ethernet destination MAC against the ARP target MAC where applicable, and ip checks for invalid/unacceptable IP addresses in ARP packets. Multiple checks can be enabled in one command.
