CDN & Networking Notes

High-level concepts for content delivery, HTTP, routing, and reliability.

CDN Fundamentals

Core Ideas

  • CDN: A distributed network that serves content closer to users for lower latency.
  • Edge POP: An edge location that caches content and responds to nearby users.
  • Origin: The source server where content is hosted.
  • Cache hit: Served from edge cache (fast, no origin load).
  • Cache miss: Must fetch from origin (slower, adds origin load).
  • TTL: How long cached content is valid before revalidation.
  • Purge: Force content removal from cache before TTL expires.

Edge Compute (High Level)

  • Edge logic: Run request/response logic closer to users.
  • Use cases: Redirects, header manipulation, routing, personalization.

HTTP & Web Delivery

Protocol Basics

  • HTTP: The protocol for client/server communication.
  • HTTPS: HTTP over TLS encryption.
  • TLS: Secures data in transit and prevents MITM attacks.
  • Headers: Metadata that controls caching, auth, and behavior.

Status & Caching

  • Status codes: 200 OK, 301/302 redirects, 403 forbidden, 404 not found, 500 server error.
  • Cache-Control: Controls how long responses are cached (e.g., max-age=3600).
  • ETag: Identifier for cache validation (saves bandwidth).

Performance Terms

  • Latency: Round-trip time for a request; lower is better.
  • Bandwidth: Amount of data transmitted per unit time.

Networking Core Concepts

Foundations

  • IP (IPv4/IPv6): Unique address for a device on a network.
  • DNS: Resolves domain names to IP addresses.
  • DNS propagation: Time for DNS changes to spread globally.
  • Anycast: Multiple servers share one IP; traffic goes to the closest.
  • BGP: Routing protocol between networks (ASNs).
  • ASN: Identifier for a network on the public internet.

Traffic Flow

  • Peering: Direct exchange of traffic between networks.
  • Transit provider: Paid network that carries your traffic to the internet.
  • Load balancing: Distributes traffic to prevent overload.
  • Reverse proxy: Sits in front of origin and forwards requests.

Reliability & Monitoring

Operational Basics

  • Uptime: Percentage of time a system is operational.
  • SLA: Availability or performance guarantee (e.g., 99.99%).
  • Incident: Event that disrupts normal service.
  • Alerting: Automated notifications for problems.
  • Observability: Understanding a system via logs, metrics, traces.

Signals & Protection

  • Logs: Events and errors (what happened).
  • Metrics: Numeric trends (latency, error rate).
  • Traces: Request-level visibility across services.
  • Rate limiting: Protects against abuse or overload.
  • DDoS: Traffic flood attack; needs mitigation.
  • WAF: Filters malicious HTTP traffic.

Edge & Config Concepts

Advanced Delivery Concepts

  • Configuration language: Defines routing, caching, and request handling.
  • Edge dictionaries: Key-value stores at the edge for dynamic config.
  • Shielding: Centralizes cache misses to reduce origin load.
  • Streaming logs: Ship logs in real time instead of batching.
